What matters most for actual bounty hunting?

Priority Topics		             Why it matters for bounty hunting
----------------------------------------------------------------------
Information disclosure               Finding secrets, sensitive files, and useful internal details
Access control                       Unauthorized access to other users' records and IDOR/BOLA vulnerabilities
Authentication                       Account access and login or password-reset weaknesses
API testing                          Finding excessive data exposure and authorization problems in APIs
Business logic vulnerabilities       Discovering application-specific flaws that automated scanners may miss
